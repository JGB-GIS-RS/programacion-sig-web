## Procedencia y límites

Estos seis ejemplos son reconstrucciones didácticas del temario del RAR, no copias verificadas de todos los programas originales. La poligonal topográfica requiere una revisión e incorporación específica.

Abrir desde un servidor HTTP estático en la raíz del repositorio: `python -m http.server 5500`, después `http://127.0.0.1:5500/practicas/02-fundamentos-javascript/`. No se afirma haber comprobado todas las interacciones en un navegador externo. No se modificó el backend PostGIS.

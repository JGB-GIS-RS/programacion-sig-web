Visor SIG Web del Quindío

Proyecto integrador · PostgreSQL/PostGIS · Python/FastAPI · Psycopg · JavaScript/Leaflet

Una interacción sobre el mapa se transforma en una consulta real a una geodatabase y regresa como JSON o GeoJSON.

Aplicación desarrollada durante la práctica

Funcionalidades F1–F5

F1

Municipios

Carga de los 12 polígonos municipales desde PostGIS.

F2

Detalle municipal

Consulta de nombre, código y superficie geodésica calculada.

F3

Identificación espacial

Determina qué municipio cubre un punto utilizando ST_Covers().

F4

Proximidad a salud

Busca sedes de salud por radio en metros con ST_DWithin() y ST_Distance().

F5

Equipamientos

Filtra sedes educativas o de salud por municipio y categoría.

Acceder al visor

La aplicación utiliza el servidor local FastAPI y la base de datos programacion_sig. No funciona desde una página estática sin ese servicio.

Abrir visor local ↗Documentación interactiva de la API ↗
Antes de abrir: inicia PostgreSQL y el backend con su archivo privado .env configurado. Los enlaces 127.0.0.1 se refieren al computador desde el cual se abre la página; no son una aplicación publicada en Internet.

Arquitectura que debes comprender

Usuario y Leaflet
      ↓ interacción
JavaScript → fetch() → HTTP GET
      ↓
Python / FastAPI → Psycopg
      ↓
PostgreSQL / PostGIS
      ↓
JSON o GeoJSON → JavaScript / Leaflet

Por dónde comenzar a estudiar

Antes de consultar los archivos por separado, utiliza la guía principal del proyecto, que explica el funcionamiento completo de manera progresiva. Para comprender las tablas y sus relaciones, consulta el modelo vigente de cuatro tablas. La guía de F5 completa la secuencia de funcionalidades.

Funcionalidades · Etapas

Iniciar en VS Code

Con el entorno virtual, las dependencias y la base de datos ya preparados, ejecuta desde la raíz del repositorio:

.\.venv\Scripts\python.exe -m uvicorn backend.main:app --reload

Los datos originales y las credenciales no están incluidos en GitHub. Una clonación del repositorio no crea automáticamente la base de datos.

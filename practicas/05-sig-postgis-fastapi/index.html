Módulo 05 · Proyecto integrador

SIG Web con PostgreSQL/PostGIS

Visor geográfico del Quindío. Aprende cómo un evento sobre el mapa llega a una consulta espacial en PostGIS y cómo la respuesta vuelve a Leaflet.

Cómo estudiar este módulo

La ruta consta de siete apartados. Comenzamos por el problema geográfico y los datos; después estudiamos la arquitectura, la preparación del entorno y las funcionalidades F1–F5. Cada apartado conduce a explicaciones y, cuando corresponde, al código realmente implementado.

Puedes seguir el orden o abrir directamente el apartado que necesitas consultar.

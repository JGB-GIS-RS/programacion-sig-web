## Procedencia y límites

Son adaptaciones de los ejercicios originales y no equivalen a una reproducción literal de todos los archivos. Los ejercicios CSS aplicados se integrarán tras revisar sus recursos y versiones.

Abrir desde un servidor HTTP estático en la raíz del repositorio: `python -m http.server 5500`, después `http://127.0.0.1:5500/practicas/01-fundamentos-web/`. No se afirma haber comprobado todas las interacciones en un navegador externo. No se modificó el backend PostGIS.
